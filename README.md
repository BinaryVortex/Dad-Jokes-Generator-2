# Dad Jokes Generator

A lightweight, front-end Dad Jokes Generator built with HTML, CSS and JavaScript. Click a button to get a fresh (and painfully funny) dad joke — perfect for demos, learning DOM manipulation, or adding a little humor to your site.

## Features

- Generates random dad jokes on button click
- Clean, responsive UI built with plain HTML & CSS
- Easy to read and modify JavaScript logic
- No build step or dependencies — open `index.html` and try it

## Built With

- HTML
- CSS
- JavaScript

## Getting Started

To run the project locally:

1. Clone the repository

```bash
git clone https://github.com/BinaryVortex/Dad-Jokes-Generator-2.git
cd Dad-Jokes-Generator-2
```

2. Open `index.html` in your browser (double-click or use a local server)

```bash
# Optionally run a simple HTTP server (Python 3):
python -m http.server 8000
# then visit http://localhost:8000 in your browser
```

## Usage

- Click the "Get Joke" (or similar) button to generate a new joke.
- The joke text will update in place. Customize the jokes list in the JavaScript file to personalize the content.

## Customization

- Add or edit jokes in the JavaScript file (likely `script.js` or similar) by modifying the array of jokes.
- Change styling in `styles.css` to match your branding.
- Replace the randomizer with an external jokes API (for example, the official Dad Jokes API) if you want dynamic content.
